# Predictify n8n Flows

Flujos automatizados construidos con **n8n** para integrar notificaciones, reportes y CI/CD.

## 🔁 Qué contiene
- Webhooks desde el backend
- Automatización de correos
- Generación de reportes
- Notificaciones automáticas (correo / Slack / Teams)

## ▶️ Uso
Importar los flujos en una instancia de n8n.
